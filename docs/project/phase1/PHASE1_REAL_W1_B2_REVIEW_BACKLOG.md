# W1-08B2：DeepTMHMM 评审准备

> 前序设计/评审参考：下文保留原时点的准备范围和结论；当前开发顺序由 [W1 交付任务](PHASE1_REAL_W1_BACKLOG.md)与 [现行计划](../PHASE1_DELIVERY_PLAN.md)覆盖。原科学未签收事实和机器证据保持原义，接手不必通读本页。

本包按用户指定顺序推进 W1 内的 DeepTMHMM，承接 [Academic 禁网实测](PHASE1_REAL_W1_DEEPTMHMM_OFFLINE.md)
与 [分模块契约](PHASE1_REAL_W1_CONTRACT_DESIGN.md)。进度、下一项和门禁只见 [STATUS](../STATUS.md)。

| 子项 | 准备交付及验收 |
|---|---|
| B2-01 输入与失败事实 | 原件/包/镜像身份；已实测、源码可见、工程支持草案和待验范围分别记录；空输入、非法字符、安全 ID、超长/资源/重复记录失败明确归属 |
| B2-02 请求与结果草案 | 单序列请求、内部安全 ID、精确输入/profile/执行绑定；三行标签和 Academic 区段表、连续段统计、P/B、损坏输出、null 与下游责任 |
| B2-03 参考与验收规格 | 已有公开标注与实际预测分离；逐样本来源/hash/训练独立性、待接收独立参考模板、验收断言及具名放行条件 |
| B2-04 限定评审与验证 | 原始输出只读复核、独立字面量正反例、Schema/语义/绑定负测，保留生产未启用与科学未签收状态 |

B2 为序列级工具；不依赖 B1 的结构映射、未知 iCode 或来源判定签收。
B1 科学确认继续独立收敛，B2 仍须满足自己的适用 G0/G1。
本项形成评审材料和离线校验器，不启用正式适配器或修改专家原件/旧证据。

FoldX、ProteinMPNN 等后续工具按 [W1 包的后续波次准备](PHASE1_REAL_W1_BACKLOG.md)
保留接口与资产准备，实际工具验证及实现由所属波次承接。此处修正任务顺序，不改变一期完整范围。
