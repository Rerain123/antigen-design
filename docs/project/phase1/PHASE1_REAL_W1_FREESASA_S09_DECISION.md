## 1. 先行采用的 FreeSASA 参数

| 项目 | 建议值与用途 |
|---|---|
| 版本 | FreeSASA 2.2.1；依赖与本地镜像 ID 写入 profile。部署到目标机还须登记离线镜像、实际版本和验收人 |
| 算法 | Lee–Richards，200 slices，1 thread；不把 Shrake–Rupley 的 n-points 当作此算法参数 |
| 半径 | 显式 ProtOr，探针半径 1.4 Å；每次保留实际逐原子半径，禁止未知原子的自动半径猜测 |
| 面积 | 取残基绝对 SASA，单位 Å²，含主链和侧链重原子；氢/氘不纳入此候选口径 |
| 归一化 | 沿用专家 C34 §2b 的 Tien 2013 Theoretical 全表；不得使用库自带 relativeTotal |
| 数组及统计 | R-58 对齐输入序列；缺失/未知位置 null+WARNING；buried_fraction=count(非 null RSA<0.20)/len(seq)，保留完整分母 |
| 异常 | NaN、负面积、超出 [0,1] 的归一化比值保留诊断，不截断、不填零。该批不产生可消费的正常 RSA 结果 |

200 slices 是本轮工程建议，不是专家原件已有常数。官方文档允许提高积分切片数；本样本中
20 slices 的最大逐残基比值差为 0.00949，100/200/400 slices 分别约为 0.000828/0.000550/0.000296。
200 slices 的原始计算约 0.061 秒，在此小样本上有足够的误差余量；这不构成大蛋白性能基准。
官方示例的默认参数和本轮候选参数分别核验，不能要求 200 slices 复现 20 slices 的精确面积。
[官方参数说明](https://freesasa.github.io/doxygen/CLI.html)

后续适配器按 C34 §1/R-05 写 method_summary：实际工具版本、profile ID/version/hash、算法与
切片数、探针/半径表、主侧链口径、输入/派生结构和映射 hash、MODEL/链/排除原子记录、
归一化表来源及警告。profile 是通过公共接口 config 引用的准备资产，当前尚未实现生产适配器。

## 2. 结构上下文也必须显式指定

| 输入情况 | 候选处理 |
|---|---|
| 一个或多个 MODEL | 单模型登记其原始编号；多模型必须明确选择，禁止默认取首个或合并。不得自动构建生物学组装体 |
| 多条蛋白链 | 同一经确认模型的指定蛋白上下文共同参与遮挡，只将唯一设计链映射回输入序列；其余链 fixed |
| 水分子 | 此候选蛋白上下文排除水，保留原始清单、数量及排除记录 |
| 配体、金属、核酸、修饰残基 | 需要单独确认计算上下文及半径表；未经确认进入复核，不能用 hetatm=false 静默丢弃 |
| altloc、占有率 | 必须记录明确构象选择；不靠解析器默认选择。占有率不作面积权重；非完整/未知占有率进入输入上下文复核 |
| 未知原子/缺原子 | 不猜半径、不自动补全。未知半径影响邻近遮挡时整批不可消费；缺失位置沿用 null 降级。完整性模板和 >20% 的分母仍由 OI-023 收敛 |
| mmCIF 转 PDB | 原件只读保存；派生文件检查身份、数量、编号、插入码和坐标精度。超出 PDB 表达能力时明确报错，禁止截断 |

这些输入处理政策随参数方案先行采用，仍待科学确认。本轮 1UBQ 只实测了单模型 A 链、排除水的数值路径；其
R-58 映射仍为 unverified，低占有率和原子完整性也未因此获批。5XZC 仅含 Cα，继续作为限制案例。
本稿不改变完整一期接收范围，复杂上下文需要补充 profile 与样本后验收。

## 3. 三层参考与容差建议

1. **外部发表值**：FreeSASA 官方文档的 1UBQ 示例给出总面积 4804.055641 Å²、MET1
   54.393508 Å²；本地 20 slices 均在示例六位小数精度内一致（舍入半宽 5×10⁻⁷ Å²）。
   这是独立来源的回归参考，但仍是 FreeSASA 算法，网页也未提供样本 hash。
   [官方示例](https://freesasa.github.io/doxygen/CLI.html)
2. **独立算法**：Biopython 1.88 Shrake–Rupley 使用相同 602 个原子的坐标、ProtOr 半径和
   1.4 Å 探针。每原子半径通过独立计算实体的 lookup token 注入，不改原结构或化学身份。
   独立的是表面积积分代码；共享半径模型不能验证化学上下文或实验真值。
   [Biopython API](https://biopython.org/docs/latest/api/Bio.PDB.SASA.html)
3. **解析几何**：孤立球、相离双球、不同半径相交双球、包含双球，用球面/球冠解析面积对照两套程序。
   这能检查探针膨胀、遮挡和面积单位，不能覆盖真实蛋白全部情况。

数值预算在首轮执行前写入 [研究规格](../../../discovery/t01-phase1-real/w1/freesasa-reference-20260905/reference_spec.json)。
它们是工程提出的**科学验收候选容差**，专家原件和论文没有给出本项目的验收容差，不冒充已批准标准。

| 检查 | 候选上限 | 本次 200 slices 对独立参考 |
|---|---|---|
| 全结构绝对 SASA 总量相对误差 | ≤0.5% | 约 0.00419%（差 0.201272 Å²） |
| 单残基归一化比值绝对误差 | ≤0.01；等价面积差 ≤0.01×该残基 Tien 分母 | 最大约 0.000550；最大面积差约 0.150805 Å² |
| 独立参考加密前后最大比值变化 | ≤0.002，作为预算 1/5 的经验收敛检查 | 15360→61440 点约 0.000842 |
| 下游判定一致性 | 不允许跨过实际消费阈值仍宣称通过；跨界转复核 | 本例 RSA<0.20 无分歧；两端十残基均值的 0.20/0.40 分档无分歧 |

首轮 3840→15360 点变化约 0.003295，未达到预设收敛条件；因此新增 61440 点运行，保留
首轮全部文件，没有放宽目标。200 slices 总面积为 4804.922802318354 Å²；独立参考为
4804.721529837215 Å²。收敛差只是经验指标，不是数学误差上界。

误差预算仅适用于相同原子、坐标、半径、映射和 null 掩码的比较。阈值判定使用未舍入值，
RSA=0.20 本身不算 buried；不设置隐形 epsilon，也不改变专家阈值。
新样本须重新检查参考收敛、缺失掩码、数值域和实际下游边界；不能将本例差值写成所有蛋白的精度保证。
尚缺独立留出样本、多链/partial/未知原子与边界样本，因此候选容差仍需科学负责人确认。

## 4. 新发现：G76 超过归一化上限（OI-027）

1UBQ 的 A:76 GLY 是末端残基。200 slices 面积为 146.977072 Å²，独立参考为 146.952325 Å²。
除以专家锁定的 G=104 后，分别为 **1.413241 与 1.413003**。这远大于本轮数值预算，两套算法
结果相近，不能解释成浮点误差；原因归属仍需科学核对，不能仅凭“末端”就宣布原因已证实。

[Tien 原文](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0080635)说明其归一化基于
指定的 DSSP 计算口径和三肽构象；本项目专家指定将该表用于 FreeSASA。论文并未提供本项目
“出现 >1 时一律截断”的许可。现有接口也要求有效 RSA 在 [0,1]，故本例目前只能提供绝对
SASA 与出域诊断，不能给出可消费 RSA、buried_fraction 或 S-39 科学结论。

**当前工程处置已经明确**：保留原值，按 OUTPUT_INVALID 返回 result=null、usable=false、
requires_review=true。需要算法裁决的是正常科学数据最终如何表示：认可出域原比值、批准上限
处理或指定其他归一化口径都会涉及专家/契约变更；本轮均不擅自采用。OI-027 只阻断相关科学
消费与验收，不阻断其他 W1 原始工具准备。

## 5. S-09 六项先行裁决

原文、章节和完整冲突见 [规则核对](PHASE1_REAL_W1_S09_RULE_REVIEW.md)。机器草案逐项列出
来源、输入、理由、边界/null 预期、S-11 影响和裁决人字段；原来的 33 项来源案例及其历史 hash 保持不变。

| 案例 | 建议裁决 | 拟定输出及下游影响 |
|---|---|---|
| D01：X-ray 4.0 Å | 采纳 SOP 分档正文的闭区间，澄清冲突注释 | medium；topology=true；掩码=null；满足 S-11 质量条件 |
| D02a：X-ray，resolution=null | 通用 null 规则优先于方法分支，依据 SOP 通用行及结构 ToolSpec §5 | medium+无法获取分辨率 WARNING、建议复核；topology=false；掩码=null；满足 S-11 质量条件 |
| D02b：cryo-EM，resolution=null | 同 D02a | 同 D02a；不改非空分辨率档值 |
| D03a：NMR 3.0 Å | 原件未覆盖，按 R-48 走复核处置，不借用 X-ray 档位 | 不生成正常 quality；failure 级 WARNING、unreliable、强制复核、禁止自动交接；诊断中的 topology 公式值为 true |
| D03b：NMR 4.1 Å | 同 D03a；适用 NMR 非空 ≥3.0 Å | 同 D03a；诊断中的 topology 公式值为 false |
| D03c：未识别实验方法，2.0 Å | 保留实验来源，转方法复核，不改为 unknown source | 不生成正常 quality；failure 级 WARNING、unreliable、强制复核、禁止自动交接；诊断中的 topology 公式值为 true |

D01 的 3.0/3.9999/4.0 为 medium，4.0001 为 low；cryo-EM 4.0 原本即为 medium，不改。
NMR null 仍为 medium、非空 <3.0 仍为 high；预测 pLDDT/pTM/低置信掩码规则不改。
缺失分辨率的 WARNING 不能补造 topology=true，也不自动满足 R-58 或 FreeSASA 原子条件。
D03 是请求复核，不能伪装成 quality=low 的正常跳过，更不能输出 confidence=null 的正常 quality。
