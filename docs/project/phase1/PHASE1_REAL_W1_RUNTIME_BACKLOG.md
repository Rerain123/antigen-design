# W1-09A：通用运行层工程实施

这是 [W1-07 设计](PHASE1_REAL_W1_CONTRACT_DESIGN.md)后的独立工程子任务。是否已放行、实际进度见
[STATUS](../STATUS.md)，限定评审结论见 [W1-08A 记录](PHASE1_REAL_W1_CONTRACT_REVIEW.json)。

## 要交付什么

建立可在开发机验证的任务运行层：接收请求、保存任务、执行受控工程 Worker、查询、取消、重启恢复，
并保留可核对的输入输出。不调用 AF3/ESMFold2，不调用其他科学工具，不接入真实 Dify 流程。
首版以单机 SQLite、受控子进程和传输无关 Python/CLI 操作为工程候选；数据库只放本地磁盘，
不承诺多机共享数据库或远程 GPU 已实现。科学 profile 默认全部关闭。

| 子项 | 实现内容 | 必须验证的行为 |
|---|---|---|
| A01 身份与存储 | 新 `t01_phase1_real` 模块、独立运行根、SQLite migrations、run/job/event/artifact/idempotency 表 | 事务回滚不留半任务；Mock/legacy/专家路径拒绝；旧资产不导入 |
| A02 创建、提交与查询 | create_run、schema/版本、请求快照、幂等事务、revision 查询、调用范围校验 | 同 key 同字节返回同对象，冲突无新 job；越权/非法请求拒绝；重启可查询 |
| A03 Worker | 固定登记的工程 Worker、原子认领、唯一执行身份、有限资源配置 | 并发只启动一次；未知工具/任意命令拒绝；启动窗口崩溃可对账 |
| A04 停止与恢复 | queued 取消、running 停止、确认进程树结束、reconciling、显式 retry | 实际子进程消失后才终止；取消/成功竞争；旧 epoch 拒绝；未知执行不重复启动 |
| A05 文件发布 | 安全物化、不可变输入、hash、临时输出和原子结果清单 | 路径/符号链接逃逸、跨 run、篡改、崩溃半文件均不可消费 |
| A06 工程验收 | CLI 入口、运行说明、独立案例与回归 | success/failure/timeout/cancel/restart/retry，全部 ENGINEERING_FIXTURE、usable_for_pipeline=false |

实现前按 contract.json 的 API、状态和身份约定，不复制冻结 Mock 的状态机/生成器作为生产源码。
科学规则字段只存储和校验，不让工程 Worker 填科学分数；不能用工程调用通过为 B/C 自动生成批准记录。
发生接口缺口先回到 W1-07 记录兼容性与影响，不在代码中静默加状态、失败回退或科学默认值。

## 验证与结束条件

以 acceptance.json 的 runtime 工程案例为最低清单，实际执行采用临时独立目录与无科学意义的字节文件。
取消/超时要用真实无害子进程及其子进程验证；恢复至少覆盖“认领后未启动”“启动后未回写”“输出已写未提交”三个窗口。
测试失败不能通过缩小进程树或只改状态绕过。性能阈值待目标需要确认，不用任意测试秒数宣称科学性能。

结束时提交源码、工程测试、CLI 演示证据、运行手册及源文件/环境 hash；分别报告工程契约、运行实现和未接入的科学能力。
按 RUNBOOK 跑当前根检查与受影响只读资产校验；跨历史分区或阶段冻结时才追加所需历史回归。
A 完成只证明基础工程可用。B/C 各自科学评审、W1 总评和完整发布继续按主线计划推进。
