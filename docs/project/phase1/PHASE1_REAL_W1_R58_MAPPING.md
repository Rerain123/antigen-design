# 本地结构解析与 R-58 映射专项

本专项由主开发推进，为 FreeSASA 及后续结构工具提供一致的“序列位置—结构残基”对照表。
它属于 W1-03 与 W1-07；进展、剩余项和验证结果以 [STATUS](../STATUS.md)为准。

## 本轮交付

- [本地解析与候选生成代码](../../../src/t01_structure_mapping/probe.py)：读取 PDB/CIF/mmCIF，保留原始文件，生成结构清单和映射候选。
- [映射规范与 Schema](../../../工作流设计/02-数据契约/tool-interface-v0.1/structure_mapping/README.md)：公共字段、状态及便携检查器，随两个同事包同步。
- [实际文件重解析检查](../../../scripts/check_structure_mapping.py)：核对映射地址与本次结构，不仅检查 JSON 的 hash。
- [测试与样本](../../../tests/fixtures/structure_mapping/README.md)：人工边界用例、从历史只读复用的公开结构及独立序列来源。
- [本次本地记录](../../../discovery/t01-phase1-real/w1/r58-local-20260905/README.md)：新运行、新证据，不继承历史通过结论。

这是一套可运行的开发探测与校验实现。生产适配器、目标服务器部署、完整 S-07c/S-09 和科学批准仍按 W1 门禁完成。
后续 [R-58/FreeSASA 边界补强](PHASE1_REAL_W1_R58_SASA_BOUNDARIES.md)补充实体位置定位、转换身份检查和原始面积对照；
最初批次的原始文件与方法声明保留当时事实。

已检索上述原件、最终 Schema 与环境清单。未发现 R-58 的通用比对评分、gap penalty 或接受阈值。
原始探测采用严格逐字、保持顺序的唯一子序列候选；后续增加完整实体序列逐字核对与 label 位置路径。
两条路径均为工程候选，不将任意评分阈值当专家规定；格式和适用限制见映射规范。

解析使用本机实测 Biopython 1.88。严格模式避免容错时丢弃残基/原子；mmCIF 显式使用作者链和作者编号，
其 API 行为见 [Biopython 官方文档](https://biopython.org/docs/latest/api/Bio.PDB.MMCIFParser.html)。
wwPDB 的 auth_seq_id 允许非整数文本，见 [字段定义](https://mmcif.wwpdb.org/dictionaries/mmcif_pdbx_v50.dic/Items/_atom_site.auth_seq_id.html)；
当前探测程序对此明确报待处理，不偷换为 label 编号。官方网页只用于格式/API 核对，没有下载结构。

## 可执行的范围

读取全部 MODEL、链和残基；保留非蛋白组分、hetero 标记、altloc 和 label/auth 对照，统计读取前后原子数。
mmCIF 另保留实体序列和 label_entity_id，核对实例声明；有完整、唯一且与输入一致的实体序列时按其位置定位。
PDB 使用文件观察顺序；mmCIF 在单一 label 链且序号完整时按 label_seq_id 恢复链内顺序，作者编号始终保留。
不覆盖原坐标，不推断结构来源，不把 B-factor 自动当 pLDDT，也不计算缺原子比例或 S-09 质量档位。

唯一候选的逐位数组与输入等长，缺失位置为 null。多个候选链、重复片段、未知残基或编号歧义保留明确问题。
多 MODEL 需显式指定索引；摄取 chain 参数不能把同源多链的科学歧义变成“已确认设计链”。

生成器不提供批准接口：输出仅为 unverified 或 unreliable。便携 Schema 和实际重解析通过后，仍由主开发协调
适用科学评审、记录决定和样本核验；只有这些证据齐备才登记 verified。其他结构工具的消费测试留各自波次。

## 样本复用决定

用户确认开发阶段暂无对方提供的真实测试用例，并授权检查冻结历史中的样本。
本轮仅复制有本地采集 hash 和独立序列来源的 1UBQ、5XZC 输入，来源记录见样本清单。
历史目录只读，不导入 S07 源码、不重新查询数据库，也不把旧项目状态或验收结论带回当前一期。

1UBQ 用于完整序列与作者坐标的工程对照。5XZC 用于多链/重复位置/仅 Cα 结构的受限案例；
它不能作为正常 FreeSASA 全原子科学验收样本。对方样本仍为暂无，算法金标准与容差仍需登记。
后续环境、样本使用范围及实体/编号/原子补充核对统一见 [W1-01/02 登记](PHASE1_REAL_W1_PREPARATION.md)。
