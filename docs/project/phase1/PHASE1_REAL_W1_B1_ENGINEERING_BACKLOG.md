# B1 前置工程补强：输入预检、元数据与原始地址

本任务承接 [B1 限定评审](PHASE1_REAL_W1_B1_REVIEW.md)，属于既有 W1-03/W1-07 的准备工作。
当前排期见 [STATUS](../STATUS.md)。目标是在本机形成可供正式适配器评审的完整事实输入，不跳过 B1 科学 G1。

| 子项 | 实现要求 | 验收要求 |
|---|---|---|
| E01 输入预检 | 校验声明格式与实际内容；检查请求 MODEL/链是否存在、是否含蛋白；记录 AUTO 候选和所有链信息 | 明确区分损坏文件、不支持格式分支、请求选择不存在；不回退选首链，不改变原序列/结构文件 |
| E02 原始元数据 | 读取 PDB EXPDTA/REMARK/SOURCE 及 mmCIF 对应 method/resolution/来源字段；保留字段名/原值/来源位置及解析诊断 | 缺失、多个值、冲突和不可解析值均可见；不计算 S-09，不把 B-factor 变成 pLDDT，不用结构物种覆盖 host_species |
| E03 原始作者地址 | 为字符型 auth_seq_id、iCode、label/auth 链建立无损原始清单；与现有整数映射格式区分 | 43A 与整数 43+iCode A 不合并；不能表示的消费者地址明确阻断，不能截短链或假装现有映射已支持 |
| E04 事实交接 | 原始输入、预检和元数据/地址事实独立 Artifact 与 hash，按 B1 草案提供可审查配对样例 | 扩展本地真实/人工边界验证；所有科学来源、缺原子比例和映射批准保持未评估，必要时回填草案差异 |

先检索对应原件与字段定义，再复用/扩展独立开发探针。若修改当前探针，须保留前后源码快照并增加新批次，
旧 R-58、B1 和运行层证据不回写；已有源码 hash 的变化要能够追溯。
不会改变当前 A 工程 Worker 的允许列表，也不将新探针注册成正式 ingest_structure/map_structure 服务。

可以由工程确定的格式与身份问题由主开发处理；B1-M01～M03、B1-A01～A03 的科学条件仍按限定评审的关闭要求完成。
结束时提供代码、独立预期、实测、接口差异及原件/旧资产只读校验；状态仅更新到实际完成范围。

实现与交付证据见 [工程补强评审](PHASE1_REAL_W1_B1_ENGINEERING_REVIEW.md)，当前完成范围仍以 STATUS 为准。
