# PH1-REAL-W1 专项 Backlog：N01–N02 真实能力

> 文档类型：执行任务包；编制日期：2026-09-05。
> 适用基线：T01-PHASE1-18NODE-OFFLINE；前序：[Mock v0.1 冻结与放行评审](PHASE1_MOCK_M4_IMPLEMENTATION_REVIEW.md)。

## 目标与边界

W1 交付 N01 输入、本地结构或 AF3/ESMFold2 预测、S-09 质量评估，以及 N02 DeepTMHMM 和条件
FreeSASA 的真实能力，依次完成 G0–G6。G0 是事实摸底，G1 是规则与接口就绪；后端实现从 G2 开始。
按 [分模块开发决定](../sources/PHASE1_W1_MODULAR_DEVELOPMENT_20260905.json)，通用工程、已有工具和预测引擎
分别按自身条件评审和实施；完整波次的科学能力、集成与发布门禁仍须全部满足。

- 从环境/样本登记和本地开发验证开始；目标服务器安装、模型推理、生产适配器和 Dify 接入按各自依赖及门禁推进。
- 使用必填目标序列、宿主物种和可选本地结构；本地部署 AF3/ESMFold2 是用户确定的方向，实际可运行性需证据。
- 删除 S-07、RCSB/AFDB 搜索及联网回退；S-07c 只取本地文件解析条款，不恢复整个 Router 或 S-07b。
- 保持 N01–N18 的身份与业务拓扑。W1 的局部链通过不等于 N03–N18、科学全链或一期发布完成。
- FreeSASA 默认实施，quality=low 的条件跳过不等于工具退出一期。进度削减仍受 OI-020 和既定顺序约束。
- 所有科学计算与判据由后端/Worker 执行；Mock 源码、Schema、provider、DSL、运行根及冻结证据不原地替换。
- 一期开发主线按波次依赖推进；许可证、数据、样本和规则归并可提前准备，不计作工具部署或门禁通过。
