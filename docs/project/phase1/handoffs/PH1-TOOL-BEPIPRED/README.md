# 同事 B：BepiPred 任务

> 任务编号：PH1-TOOL-BEPIPRED · 交接资料 v0.1 · 2026-09-05

## 你要做什么

给定一条蛋白序列，在本地运行 BepiPred 3.0，取得每个残基的预测分数，
再按项目规则提取连续区段（linear_peaks），输出可检查的 JSON 结果。

“残基”可以先理解为序列中的一个位置。“峰”是满足项目规则的一段位置区间。
这些结果供后续表位地图使用，你本次负责 BepiPred 工具及其结果解析。

本包说的 G0 是“先核实原工具的实际运行情况”，G1 是“主开发确认规则和接口可以开始实现”。
SHA-256 是文件指纹，用来核对文件内容；commit 是这份工具源码的具体版本标识。

## 做到什么程度算交付

- BepiPred 3.0 在约定环境真实运行，模型和依赖可在内网使用。
- 原始逐残基分数完整保留，坐标和输入序列一一对应。
- 按确认后的项目规则输出 linear_scores 和 linear_peaks，异常时明确失败。
- 提供独立 Python 适配器、命令行入口、测试、版本记录和离线运行说明。
- 由参考样本验证结果，在干净环境复现后交主开发集成。

本次只做 BepiPred，不承担 NetMHCpan/IIpan、IEDB、DiscoTope、表位地图合成或 Dify。

## 首次接手记住三点

版本使用项目指定的 3.0；分数与位置必须完整保留；遇到规则不明确，把具体输入和原始结果交回。
后处理需要确认的事项已经列在实现说明中，不需要你另写一份宽泛问题清单。
