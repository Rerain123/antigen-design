# 同事 A：FreeSASA 任务

> 任务编号：PH1-TOOL-FREESASA · 交接资料 v0.1 · 2026-09-05

## 你要做什么

给定一份蛋白结构文件和它与输入序列的对应表，调用 FreeSASA 计算每个残基的表面积，
再按项目指定的参考表转换成 RSA，输出可检查的 JSON 结果。

“残基”可以先理解为序列中的一个位置。SASA 是绝对面积，单位 Å²；RSA 是用参考面积归一化后的数值。
后续流程会用这些结果判断表面暴露情况。你本次负责这个工具及其结果转换。

本包说的 G0 是“先核实原工具的实际运行情况”，G1 是“主开发确认规则和接口可以开始实现”。
SHA-256 是文件指纹，用来核对两边拿到的是否为同一份文件；null 表示缺少可用值，不等于 0。

## 做到什么程度算交付

- 能在约定环境真实运行 FreeSASA，保留原始输入、结果和命令。
- 能输出与输入序列等长的 RSA 数组，正确处理缺失位置、插入码和错误。
- 按主开发确认的接口交付独立 Python 适配器及命令行入口。
- 交付源码、环境锁定记录、样本与来源、测试结果、离线运行办法和未解决问题。
- 在干净环境按你的说明复现；科学结果经参考对照和算法验收。

Dify、MCP 服务、设计门控和完整项目编排由主开发集成。本任务不扩展到其他工具。
