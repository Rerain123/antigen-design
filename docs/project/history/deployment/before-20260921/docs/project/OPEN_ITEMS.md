**2026-09-12 补充：默认热点阈值不可达的条件推导（OI-007/028）。** 按 SOP S-19 每区间取最高 E 级、通道归一值≤1 的口径，一期 B 通道仅 BepiPred，最高 E1 权重0.2；T 通道即使多 allele 强结合，最高 E2 权重0.5。无 IEDB/DiscoTope 时，默认 B/T 各0.5，合成上界为 `0.5×0.2+0.5×0.5=0.35`；单通道归一后 B≤0.2、T≤0.5，均不能满足严格 `>0.5`。因此零热点可能是默认规则的必然结果，不能归因于某条测试序列差。此推导依赖上述赋级/归一化假设，T细胞呈递热点与此加权热点分别判断。算法须核对该解释并签收零热点下 N11权限、N13保护/空验证区间与N18披露规则；S-19 零热点后仅保护 E3/E4 的提示在当前来源缺省下也需给出唯一消费语义。保留非空功能/结构/用户约束，不自动降低阈值或增回已排除来源。[可复核上界](../../discovery/t01-phase1-real/deployment-review-20260912/probes.json)

## CamSol 参数与模式计数的定点复核（OI-025）

2026-09-12 只读复核确认原 `camsol_params.json` 的 `mu_random/sigma_random` 仍为 null、Roseman values 为待填，文件与原 sidecar/hash 一致。C44 §2b 已明确随机肽 N=200、N_S=100000及SWISS-PROT频率方法，不应把已给参数重新提交算法选择。后端落实频率数据版本、可复现随机源和数值计算；算法签收具体科学解释及独立参考。使用另行版本化的派生参数资产，未经授权不改专家原件。

对 OI-025 既有符号争议补充两个精确边界：

- 单纯全局交换 H/P 不改变 HPHPH/PHPHP 两种对称交替模式的命中；对长度5–9的29403个 H/P/neutral 字符串已穷举验证。因而不能把纯 H/P 命名对换描述为必然改变 I_pat 或全蛋白分数。该事实不批准参数值、非对称变换或后续公式，只将表的来源/命名确认与不受影响的工程计算分开。[探针](../../discovery/t01-phase1-real/deployment-review-20260912/probes.json)
- 更直接影响计算的是 C44 §2b 第③条“五残基（及更长）交替段”与其7残基示例。仅计滑动5残基窗口时，HPHPHPH 中心被计3次；若把5、6、7残基全部子段分别计数则为6次。原文引用与§7映射倾向五残基窗口，但措辞仍需算法明确。**建议采用固定5窗口、允许重叠，较长交替段通过多个5窗口贡献**，由算法确认后后端先固定该定义，再生成 μ/σ 和参考 profile，避免标定后重算。符号命名、计数定义、数值资产与科学参考分别关闭，不能以一种假设直接宣称 CamSol 对标完成。
