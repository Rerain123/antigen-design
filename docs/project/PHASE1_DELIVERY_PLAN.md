### 按原件补齐的执行原则

2026-09-29 的新增实施边界以“专家修订核心实施”及v2为准：v2已明确的政策不再笼统等待专家，按待校准配置实现；仍缺的具体分支不按下文历史“临时口径”条款自行补定。旧 Top40、全池结构验证、热点同一性、几何硬过滤及排序规则保留原版本适用范围，不能与修订配置静默混用。

按 2026-09-26 最新决定，专家文档指导工具编写和业务流程；第一版允许结果偏差及受限实现，不把完整科学符合性、全部数据或具名签收当作内部跑通前置。优先修复确定的程序错误并采用原文已有规则，不能用“第一版”掩盖能直接修复的错接、漏执行或状态丢失。历史 M1 可复用代码和临时处理须重新核对适用性，不能直接追认为专家规则。

- 原件已明确的公式、默认值、可配置参数、降级和条件跳过直接实现；“经验值待回测”保留其标注和配置能力，不改成必须重新取得阈值才能开发。科学消费签收仍按适用门禁单独处理。
- 实现方式、批处理、持久化、接口适配、来源校验和数值验证由工程解决，不逐项要求专家决定。原文存在歧义时，可按原文示例、固定工具事实或已有可复现实现选择有依据的临时口径用于第一版内部执行，记录选择理由、版本、与原文差异和影响；不冒充专家确认。不需要因每个此类问题再次停工询问。完全缺乏依据的数据/数值不得编造，按缺项处理；确实无法执行且无可用退路时才汇报具体阻塞。
- 数据资产缺失与规则缺失分别记录。原件允许无该资产时，完成其规定的缺失/降级分支；有资产分支的实现和真实验证另列证据，不能要求每次运行都产生阳性结果，也不能只验空分支就宣布全部能力完成。
- 不新增 HiMat 输入或恢复一期已排除工具来绕过缺项；不凭空编造宿主面板、分数或放宽已明确硬过滤来制造合格候选。必要的计算预算/代表池限制可作为第一版显式配置，记录实际覆盖和未执行部分，不能静默截断或冒充全量完成。最新用户范围决定继续适用。
- 下文原件条款和原 1–6 项保留为完整能力差异清单。漏列要求仍登记所属项，但按是否阻断当前流程安排，不再逐项全量关闭后才联调。未完成检索、未编写代码、未准备公开参数或未运行验证不能归为专家文档不足。
- 分开登记“第一版已实跑/受限/未通”与“完整专家要求已完成/仍有差异”。部署成功不等于流程实跑成功，第一版流程通过也不等于完整节点完成。科学资格保持原状态；未签收输出可以带内部试运行身份在本轮后端链中接续，不能仅因全局科学 Gate CLOSED 把所有计算挡住，也不因此开放正式科研消费或 Agent C 自动交接。
