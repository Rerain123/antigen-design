# 公开范围

本仓库是当前工程实现的独立公开副本，使用全新 Git 历史，与内部完整交接仓库分别维护。首次导出日期：2026-10-14。

## 包含

- 当前后端及结构映射 Python 实现。
- 工程 JSON Schema、任务状态契约与代码所用的部分资产配置清单。
- 精选运行入口、模块依赖与容器参考配方。
- 不依赖私有原件或真实运行结果的精选测试。
- 为公开版编写的项目介绍、架构、开发与范围说明。

## 排除

- 专家原始文档、附件、专家参数文件，以及嵌入源码目录的专家材料副本。
- 内部计划、过程记录、专家沟通、原始科学运行证据及历史报告。
- 私有部署清单、集群与设备标识、凭据、运行数据库、日志和任务目录。
- 模型权重、离线镜像、安装包、数据库及其他大型资产。
- 历史 Mock、旧工作流与根目录下独立的工具部署项目。
- 原内部仓库的任何 Git 提交历史。

## 使用前提

保留的工程资产清单仅描述代码所要求的依赖和校验身份，不表示资产本身已随仓库提供。源码中对专家文档的路径、名称与哈希引用属于依赖声明，原文不在公开树内。CamSol 等相关专家参数与校准运行资料也未提供；依赖这些资料的动作无法仅凭公开仓库执行。

源码清单记录导出文件的字节数与 SHA-256，以及导出时的个别测试脱敏变更；清单不包含本页等新写的公开文档或清单自身。公开版没有附加新的开源许可声明，第三方工具和模型的使用及再分发仍应遵守各自许可。
