# GitHub 公开仓库说明

本仓库在2026-10-14按用户最新要求扩充为完整项目交接资料的公开副本。恢复原有项目介绍、完整项目文档、源码、测试、脚本、Dify编排、部署配置、历史记录、归档证据和已有依赖包，不再使用精选源码范围。

## 与内部完整交接版的差异

专家原件、附件和参数文件不公开；除了原始目录，还检查同内容副本、ZIP / TAR / GZIP 包和部署快照中的 Base64 载荷。混合包只移除专家成员，保留其他成员；无法完整解码核查的历史截断载荷字段单独排除，其他字段保留。具体见 [排除清单](../reports/github-public-20261014/exclusions.json)。少量文本中保留原件名称、路径、哈希和引用，供有权访问原件的团队定位，不包含原件正文。

真实凭据、个人环境、虚拟环境及临时缓存不入库。模型权重、离线镜像、大型数据库等资产继续按用户此前选择保留在现有存储，位置见 [外部资产清单](../reports/handoff-20261014/external-assets.json)。这部分与完整交接范围一致，并非本次额外精简。

公开版使用独立Git历史，没有导入内部仓库历史。原项目文档、证据和清单中的部署状态、完整性与验收结论属于其记录时点及原始内部资料，不自动成为本公开副本的验收结果。

## 专家材料过滤对校验的影响

为防止专家原件藏在部署载荷内，部分公开压缩包和ConfigMap载荷已过滤；变更前后SHA-256见 [过滤变更清单](../reports/github-public-20261014/filtered-containers.json)。其中的原始部署清单、签名或hash可能仍指向完整内部版本，不能直接部署或当作原始冻结证据使用。原工作区和Codeup中的原件、快照、清单均未修改。

缺少专家原件的运行、构建、科学执行指纹和文档完整性检查会按原规则拒绝或报告缺项，本次没有绕过校验。科学生产运行需由授权团队补齐原件、受许可工具和外部资产。公开副本的工程抽查不能替代完整科学验收。
