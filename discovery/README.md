# 当前一期取证区

本目录接收当前一期任务包定义的非生产 discovery/取证。取证应关联任务、目标环境、
原始输入输出、版本和证据来源；discovery 通过不代表科学验收或生产部署。

当前任务与取证安排见 [STATUS](../docs/project/STATUS.md)和
[一期任务索引](../docs/project/phase1/README.md)。

S07 既有批次从 [S07 备用包](../legacy/s07/README.md)追溯，不用于推导当前一期规则或生产结论。

2026-10-14 项目交接将可入库的机器取证批次随 Codeup `main` 保留，原路径和来源身份不变。
大型运行资产、凭据及临时缓存的边界见[项目交接入口](../docs/project/HANDOFF.md)与其资产清单。
复核历史证据时保持资产只读；如测试依赖本机 `var/` 或模型/数据库，先按清单恢复对应资产，
不得用新生成结果覆盖旧取证或沿用旧 hash。
