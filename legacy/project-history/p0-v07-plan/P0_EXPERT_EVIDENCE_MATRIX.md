## 当前输入依据

| 事项 | 已有原文/决定 | 当前归并动作 |
|---|---|---|
| 目标序列 | `protein_sequence`，必填 | 固定规范化、合法性、哈希、长度与错误证据 |
| 宿主物种 | `host_species`，必填 | 统一旧 `host` 迁移，不制造第二事实源 |
| 可选结构 | 本地 PDB/CIF/mmCIF；可选 chain，默认 auto | 外部输入映射为受控 ArtifactRef；禁止 ID/URL 联网解析 |
| chain | auto 时选首条 protein chain，排除核酸/配体；多蛋白链告警 | 固化确定性选择与警告用例 |
| 解析异常 | 不可解析结构失败；原子缺失比例 >20% 告警 | 固化稳定错误/警告，不静默改写 |
| 序列—结构一致性 | R-58 约束多链、缺失残基和 insertion code | 结构依赖步骤前由后端执行；OI-015 收敛细节 |

## 使用边界

- 专家资料能回答的字段、格式和行为直接引用归并；只有真实冲突或科学缺口才定点上报。
- ToolSpec 描述能力不等于工具已部署。所有当前科学工具仍为 `NOT_DEPLOYED`。
- S-07、RCSB PDB、AlphaFold DB、BLAST/UniProt 回退不属于当前矩阵，也不得由历史资料恢复。
