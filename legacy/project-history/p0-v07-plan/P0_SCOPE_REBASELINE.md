## 1. 先区分三个容易混淆的概念

1. **“一期”**：边界说明中的完整一期产品，包含 18 个业务节点、6 个业务阶段。
2. **“P0”**：一期产品的第一个业务阶段，即“结构与基础分析”，不是整个一期。
3. **“P0a/P0b/P0c”**：旧算法图沿用的工具优先级标签，分布在完整 T-01 链上；它们不是 P0
   阶段成员关系，不能用来扩大 P0 范围。

因此，P0 范围应从“六阶段流程图的第一阶段”读取，而不是把所有标有 P0a/P0b/P0c 的工具都
纳入阶段 0。

## 3. 重新定义后的 P0

P0 的业务名称固定为：**结构与基础分析**。

P0 当前包含四个 S 步骤和一个甲方输入入口，组成两个业务节点：

| 业务节点 | S 步骤 | 作用 | 工具/实现 | 执行条件 |
|---|---|---|---|---|
| 01 结构预测 | 甲方输入入口 | 接收并校验目标蛋白序列、宿主物种和可选结构 | 后端确定性校验；专家文档条款由 OI-023 归并 | 必跑；不得联网补齐 |
| 01 结构预测 | S-08 `predict_structure` | 未提供合法结构时，按甲方序列预测结构 | 甲方服务器上的 AlphaFold3、ESMFold2 | 输入校验通过且没有可用结构时 |
| 01 结构预测 | S-09 `assess_structure_quality` | 对甲方结构或预测结构形成来源、质量和可信度事实 | 后端确定性计算 | 获得可解析的输入/预测结构后 |
| 02 结构基础分析 | S-04 `predict_topology` | 预测跨膜区、膜内外区域和信号肽 | DeepTMHMM | 必跑；工具失败按权威降级语义表达 |
| 02 结构基础分析 | S-11 `compute_rsa` | 计算逐残基 SASA/RSA 与表面暴露 | FreeSASA + R-58 映射 | 结构质量非 low 时；low 时明确跳过并令 `rsa=null` |

规范流程为：

```text
目标蛋白序列 + 宿主物种 + 结构（可选）
  -> 输入契约校验、结构解析与哈希
  -> 是否提供且可解析的结构？
       ├─ 是：直接作为结构事实
       └─ 否：S-08 AlphaFold3/ESMFold2 结构预测
  -> S-09 结构质量评估
  -> S-04 拓扑预测
  -> quality != low ?
       -> 是：S-11 RSA
       -> 否：rsa=null + 明确跳过原因
  -> P0 基础证据结果
```

S-11 属于 P0 完整业务范围，同时由最新基线确认为削减池第 3 顺位，排在 S-30、S-12 之后。
当前没有触发削减的用户决定，因此 P0 v0.7 默认完整 profile 继续包含 S-11。若要冻结不含 S-11
的 profile，必须先关闭 OI-020，明确名称、阶段解锁、节点 13 L2、输出缺失和验收规则。

## 4. P0 输入与输出边界

### 4.1 直接科学输入

- 必须有甲方提供且经确定性校验的目标蛋白氨基酸序列和宿主物种；规范字段采用专家 Schema 的
  `protein_sequence`、`host_species`。
- 系统不得把 accession、名称、物种或自由文本用于联网解析或替换甲方提交序列。
- 结构为可选输入；专家 SOP/ToolSpec 已给出 PDB、CIF、mmCIF，本地解析、保留原格式、可选 chain、
  解析失败和缺失原子警告等规则。结构输入不恢复 S-07 数据库检索。
- T-01 顶层还可能要求宿主等业务输入；未被本阶段科学步骤消费的字段只随请求上下文透传，
  不因进入 P0 而擅自参与科学判断。

### 4.2 阶段输出

P0 应至少形成以下可追溯事实，精确 Schema 在后续契约重建中冻结：

1. S-08 预测结构或明确失败结果；包括输入哈希、模型/工具、原始文件引用和版本信息。
2. S-09 质量结果；包括原始质量事实、`high/medium/low` 和降级/警告。
3. S-04 拓扑结果；包括逐残基标签、区段、`tm_count`、`outside_length`、`has_signal`，或明确的
   `null/unreliable`。
4. S-11 RSA 结果；包括逐残基值、缺失位置和 `buried_fraction`，或明确的未执行/失败原因。
5. 每一步的状态、错误、版本、参数档案、输入哈希、ArtifactRef 和 Provenance。

P0 只交付“结构与基础分析证据”，不在本阶段形成表位、保守性、可开发性、设计候选、排序或
Agent C 交付结论。

## 5. 当前明确排除项

- **S-06/PSORTb 不属于一期或 P0。**该范围已由 2026-09-03 最新用户基线确认；不实施、不打包、
  不作为 P0 冻结条件，旧 Mock/SOP/算法图引用只作历史与迁移证据。
- **S-07 自动结构检索不属于一期或 P0。**RCSB PDB、AlphaFold DB 及其 BLAST→UniProt→AFDB
  回退均不实施、不打包、不作为 P0 门禁；既有 discovery 只作历史证据。
- S-07b 的 PDB ID 联网下载不恢复；S-07c 已写明的本地 PDB/CIF/mmCIF 解析规则可迁入输入层，
  但不把 S-07 搜索步骤重新纳入一期。
- S-03 及其后的表位、保守性、可开发性、设计、排序和交付步骤均不属于 P0。
- 外部 `context_scores` 注入仍按现有决定禁用，不作为 P0 的替代入口。
- Mock 中为兼容既有回归保留的旧 P0/S-06 节点不构成生产范围；代码迁移在新实施计划与契约
  冻结后另行处理。
