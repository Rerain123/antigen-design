# T-01 Antigen Design

抗原设计工作流的后端工程实现。此仓库公开当前项目源码、工程数据契约、精选单元测试和开发文档，供阅读、集成与二次开发参考。

系统把任务编排、离线科学工具执行与结果解释分开：LLM / Dify 负责收集输入、调用与解释；后端负责输入校验、计算、门控、任务状态及结果溯源。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `src/t01_phase1_real/` | 持久化任务运行时、REST / MCP 服务、Worker 与离线工具适配 |
| `src/t01_structure_mapping/` | 结构解析、残基映射与结构输入检查 |
| `scripts/` | 运行时、Worker 启动及 IEDB 投影构建入口 |
| `工作流设计/02-数据契约/` | 任务与工具接口的工程 JSON Schema |
| `tests/` | 不依赖私有科学资料的精选工程回归 |
| `requirements/` | 分模块依赖及工具容器参考配方 |
